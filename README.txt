Uruchomienie:
1. Wgraj cały folder na hosting HTTPS.
2. Otwórz adres w Chrome na Androidzie.
3. Wybierz "Zainstaluj aplikację" / "Dodaj do ekranu głównego".
4. Ustawienia premium zapisują się lokalnie w urządzeniu.

Aktualizacja receptur:
- Najprościej aktualizować plik data.js i wdrożyć go ponownie.
- Po zmianie aplikacji zwiększ CACHE w sw.js, np. roq-tools-v2, aby wymusić odświeżenie cache.
